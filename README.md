# Estudios viales

Plataforma abierta para estudios viales urbanos: levantamiento en campo desde el celular, normalización de aforos, cálculo de capacidad y nivel de servicio, y memoria técnica.

- `campo/`: app de levantamiento (web instalable, funciona sin conexión). Publicada en GitHub Pages.
- `estudios_viales/`: motor de cálculo y servidor local.
- Los estudios con datos de clientes se guardan fuera de este repositorio y nunca se suben.

Diseño y plan: `../docs/`.
